# AI Document Intelligence Platform

Production-grade backend platform for secure document ingestion, AI-powered extraction, async workflow processing, caching, and cloud-native deployment.

## Tech Stack

- Node.js + TypeScript
- Express.js
- PostgreSQL + Prisma
- Redis
- BullMQ
- OpenAI/Gemini
- Docker
- Kubernetes
- AWS (EKS, RDS, S3, ElastiCache)

## Core Capabilities

- JWT Authentication
- Secure File Upload
- AI Document Parsing
- Async Background Workers
- Redis Caching
- Distributed Rate Limiting
- Structured Logging
- Cloud Native Deployment
